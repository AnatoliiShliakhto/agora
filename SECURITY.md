# Security

This is an educational open-source project simulating an exchange for a game world. It does not
custody real assets and has no production deployment.

Report vulnerabilities (ledger conservation breaks, replay/idempotency bypasses, denial-of-service
of the API) privately to a.shlyakhto@gmail.com rather than in a public issue. Expect an
acknowledgement within a week.

Dependency advisories are checked by `cargo deny` in CI.

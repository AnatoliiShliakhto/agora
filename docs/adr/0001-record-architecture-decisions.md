# 0001. Record architecture decisions

Date: 2026-08-26
Status: accepted

## Context

The project is built by several engineers and agents over a short period. Decisions made in
chat are lost; decisions made in code are invisible.

## Decision

Every architecturally significant decision is an ADR in `docs/adr/`, following the template.
`docs/PLAN.md` tasks that decide something produce an ADR as a deliverable.

## Consequences

Small overhead per decision; no re-litigation of settled questions; newcomers can read why.
